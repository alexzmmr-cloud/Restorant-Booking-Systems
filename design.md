# Design.md — Verde Marea Booking System

Визуальная система проекта. Пользовательский и административный контуры используют одни и те же токены — не два разных продукта, а два режима одного.

## Палитра

- `--color-primary: #1F4D3A` — глубокий зелёный (морская зелень), основной брендовый цвет: заголовки, кнопки основного действия, активные состояния
- `--color-accent: #C7A76C` — тёплое золото, акцент: выделения, иконки статуса, hover на второстепенных элементах, декоративные линии
- `--color-background: #F5F1E8` — тёплый молочный, фон страниц и карточек
- `--color-text: #1B1B1B` — почти чёрный, основной текст

Производные оттенки (допущение, для состояний и поверхностей):
- `--color-primary-hover` — затемнение `--color-primary` на ~8%
- `--color-surface` — белый или `--color-background` с лёгким затемнением для карточек поверх фона
- `--color-border` — `--color-text` с прозрачностью ~12% для тонких разделителей
- `--color-error` — стандартный красный для ошибок (не входит в основную палитру бренда, используется точечно только в состояниях ошибки)

## Шрифты

- Заголовки — `Cormorant Garamond` (serif, элегантный, ресторанный характер)
- Текст интерфейса, кнопки, формы — `Manrope` (sans-serif, читаемость в UI)
- Альтернатива при недоступности через веб-шрифты — системный serif/sans-serif стек с сохранением пропорций (заголовок serif, интерфейс sans-serif)

## Токены отступов и радиусов
- Шаг отступов — кратно 4px (4, 8, 12, 16, 24, 32, 48)
- Радиус скругления карточек и крупных блоков — 12px
- Радиус скругления кнопок, инпутов, бейджей — 8px
- Тень карточек — мягкая, низкий контраст (не более 10% непрозрачности чёрного)
- Transition интерактивных элементов (кнопки, инпуты, строки таблиц) — `.2s` на все свойства, единый по всему проекту
- Transition хедера (появление тени при скролле) — `.3s ease-in-out`

## Хедер
- Паттерн: прозрачный хедер поверх hero-изображения, тень появляется только при скролле
- На лендинге/странице бронирования с hero-изображением ресторана — хедер прозрачный (фон `--color-text` с прозрачностью ~25%, белый текст), без тени
- При скролле вниз добавляется класс `.scrolled` — появляется мягкая тень (`box-shadow: 0 8px 30px rgba(0,0,0,.15)`), сам фон резко не меняется, переход плавный через `transition: .3s ease-in-out`
- На внутренних страницах без hero (личный кабинет, административный контур) хедер сразу непрозрачный: фон `--color-background` или `--color-surface`, текст `--color-text` — тёмный текст не должен теряться без тёмной подложки

## Кнопки
Три чётких состояния, а не только hover — так интерактивность считывается яснее.

- Первичная (заливка) — фон `--color-primary`, текст `--color-background`
  - hover — светлее, `--color-primary-hover` (осветление ~10%)
  - active (момент клика) — темнее базового (затемнение ~10%)
- Вторичная (outline) — прозрачный фон, обводка `--color-primary`, текст `--color-primary`
  - hover — не заливать фон, только светлее текст/рамка (переход на `--color-primary-hover`) — сдержаннее, чем у заливной кнопки
- Active-selected (выбранный фильтр/таб, состояние выбора, не hover) — полупрозрачная заливка акцентом: фон `--color-accent` с прозрачностью ~40%, текст `--color-primary`
- Опасное действие (отмена/удаление) — обводка/текст `--color-error`, фон прозрачный, hover — заливка `--color-error` с белым текстом
- Disabled — сниженная непрозрачность (~40%), курсор `not-allowed`
- Все переходы между состояниями — `transition: all .2s`, без задержек

## Формы
- Инпут — фон `--color-surface`, обводка `--color-border`, при фокусе обводка `--color-primary`
- Свой focus-стиль вместо голого браузерного outline: `outline: none` заменяется рамкой `--color-primary` — не убирать outline без замены (важно для доступности)
- Ошибка валидации — обводка `--color-error`, текст ошибки под полем мелким шрифтом `--color-error`
- Лейблы — `Manrope`, текст `--color-text`, средний вес

## Карточка
- Фон `--color-surface`, радиус 12px, мягкая тень, внутренний отступ 16–24px
- Используется для карточек стола, карточки бронирования в личном кабинете
- Hover на карточке стола (в форме бронирования) — приподнятая тень (увеличение блюра/непрозрачности тени) + рамка `--color-accent`, `transition: all .2s`

## Таблица / список (административный контур)
- Строки на фоне `--color-background`, чередование с лёгким оттенком `--color-surface` для читаемости
- Заголовок таблицы — `Manrope`, полужирный, `--color-text`
- Hover на строке — лёгкая заливка `--color-accent` с прозрачностью ~8%

## Бейджи статусов бронирования
- `pending` — фон `--color-accent` с прозрачностью, текст `--color-text` (ожидание, нейтрально-акцентный)
- `confirmed` — фон `--color-primary` с прозрачностью, текст `--color-primary` (подтверждено, брендовый зелёный)
- `cancelled` — серый фон, приглушённый текст (нейтральное, не является ошибкой пользователя)
- `completed` — фон `--color-primary`, текст `--color-background` (заполненный, завершённое положительное состояние)
- `no_show` — фон `--color-error` с прозрачностью, текст `--color-error`

## Уведомление (Notification)
- Компактная карточка/строка в списке уведомлений
- Непрочитанное — маркер точкой цвета `--color-accent` слева, лёгкое выделение фона
- Прочитанное — без маркера, приглушённый текст

## Состояния
- Loading — скелетон-заглушки в тон `--color-surface` с лёгкой пульсацией, без спиннеров поверх контента
- Empty state — иконка/иллюстрация в приглушённых тонах + короткий текст на `Manrope` + при возможности кнопка основного действия
- Error state — текст на `--color-error`, без агрессивных модальных перекрытий там, где хватает инлайн-сообщения

## Правила согласованности
- Один и тот же набор токенов используется в гостевом и административном контуре — различается компоновка (таблицы/фильтры в админке), не палитра и не типографика
- Serif (`Cormorant Garamond`) — только для заголовков и акцентных чисел (например, крупная дата), не для текста форм и таблиц
- Все интерактивные элементы (кнопки, инпуты, строки таблиц) имеют явное hover- и focus-состояние
- Единый transition `.2s` на кнопках/инпутах/строках и `.3s ease-in-out` на хедере — быстрый, но не резкий отклик по всему интерфейсу

## Источники
- Паттерны хедера, состояний кнопок и hover-эффекта карточек адаптированы из внешнего дизайн-референса — цвета и радиусы взяты из палитры Verde Marea выше, не скопированы с референса
